# 화면·블록 구조 (1차시 확정본)

이 문서는 앞으로 만들 화면과 블록의 구조를 확정한다. 코드보다 먼저 읽는다.

## 1. 화면 구조

세 개의 화면(라우트)으로 나눈다.

| 경로 | 화면 | 하는 일 |
|---|---|---|
| `/` | 시작 화면 | 내 실험 목록(카드), 새 실험 만들기, 검색 |
| `/exp/:id` | 편집 화면 | 블록을 위→아래로 쌓아 계산 |
| `/exp/:id/export` | 내보내기 | 측정 결과·계산 결과 표 복사, 그래프 PNG 저장·복사 |

- 로그인(`/login`)을 해야 나머지 화면을 볼 수 있다. 실험은 **Supabase**(`experiments` 표)에 저장한다.
- 저장·불러오기는 모두 인터넷을 거치는 async 함수(`lib/storage.js`)다. 그래서 시작·편집 화면은
  "불러오는 중 / 오류" 상태를 가지고, 편집 화면은 수정을 멈춘 뒤 0.8초 뒤에 한 번만 자동 저장한다.
- 예전에 이 브라우저(localStorage)에 저장한 실험은 시작 화면의 "가져오기"로 계정에 옮긴다 (`lib/localImport.js`).

### 컴포넌트 트리 (2차시 기준 실제 구조)

```
App                         라우터 (/, /exp/:id, /exp/:id/export)
├─ HomePage                 시작 화면 — 검색창·실험 카드 목록을 이 안에서 직접 렌더
├─ EditorPage               편집 화면
│  ├─ BlockList             블록들을 순서대로 렌더 + 이동·삭제 버튼
│  │  ├─ MeasureBlock       측정 블록
│  │  ├─ CalcBlock          계산 블록
│  │  └─ GraphBlock         그래프 블록
│  └─ AddBlockButton        블록 추가 (측정/계산/그래프 선택)
└─ ExportPage               내보내기 — 표 2개(측정·계산)와 그래프를 보고서용으로 보여주고 복사·저장
```

계산 로직은 화면 코드(`components/`)와 분리해 `lib/`에 둔다.

| 파일 | 역할 |
|---|---|
| `lib/stats.js` | 측정값 붙여넣기 해석, 평균, 표본표준편차(n−1), A형·B형·합성 불확도 |
| `lib/calc.js` | 계산 블록 ↔ engine.js 연결 (이름 → 위쪽 측정 블록의 평균·합성불확도) |
| `lib/engine.js` | 수식 파서 + 자동 미분 + 불확도 전파 + 유효숫자 (직접 구현, 수정하지 않음) |
| `lib/blocks.js` | 블록 생성, 이름 목록, 중복 검사, 수식 안 이름 치환, 참조 검사 |
| `lib/regression.js` | 추세선 6종(직선·원점 직선·2차·거듭제곱·지수·로그) 최소제곱 계산, R², 표준오차, 식 글자 |
| `lib/graph.js` | 그래프 블록 자료(점·오차막대·추세선) 만들기, 축 눈금·범위 계산 |
| `lib/report.js` | 내보내기용 표(측정 결과·계산 결과)와 그래프 자료를 원본에서 새로 계산 |
| `lib/exportTable.js` | 표 → 클립보드 글자(TSV)·HTML 변환 |
| `lib/exportBrowser.js` | SVG → PNG 변환, 파일 저장, 클립보드 복사 (브라우저 기능) |
| `lib/supabase.js` | Supabase 연결 (주소·키는 `.env`에서 읽음) |
| `lib/auth.jsx` | 로그인 상태(AuthProvider/useAuth), 로그인·가입·로그아웃 |
| `lib/storage.js` | 실험 목록·불러오기·저장·삭제 (Supabase) |
| `lib/experimentRow.js` | 앱 객체 ↔ DB 한 줄 변환 (순수 함수, 테스트 있음) |
| `lib/localImport.js` | 예전 localStorage 실험 읽기·정리 (가져오기 전용) |

검색창·카드는 처음 계획과 달리 `SearchBar`/`ExperimentCard`로 따로 떼지 않고
`HomePage.jsx` 안에 그대로 뒀다 (목록이 단순해서 분리할 이유가 아직 없음).

## 2. 데이터 구조

### 계산 결과는 저장하지 않는다

원본(측정값, 수식, 축 설정)만 저장하고, 화면을 열 때마다 engine.js로 다시 계산한다.
계산 방식을 고치면 예전 실험에도 자동 반영된다.

### 실험 (experiment)

```js
{
  id: "uuid",
  title: "단진자로 중력가속도 측정",
  createdAt: "2026-09-07T...",
  updatedAt: "2026-09-07T...",
  angleUnit: "deg",        // "deg" | "rad"  — 삼각함수 각도 단위 (실험 전체 공통)
  blocks: [ ...블록 배열, 화면에 보이는 순서 ]
}
```

### 블록 공통

```js
{
  id: "uuid",
  type: "measure" | "calc" | "graph",
  name: "L",               // 다른 블록이 변수로 참조하는 이름. graph는 없음
  // type 별 추가 필드는 아래
}
```

저장: 실험은 `experiments` 표의 한 줄, 블록 배열 전체는 그 줄의 `blocks` 칸(JSON)에 들어간다
(`supabase/schema.sql`). 블록 순서는 배열 순서 그대로 보존된다.

### 측정 블록 (measure)

```js
{
  ...공통,
  type: "measure",
  name: "L",
  unit: "m",
  rawText: "1.001\n0.998\n1.002\n1.000",   // 붙여넣은 원문 그대로 (엑셀의 줄바꿈·탭 구분 포함)
  typeB: "0.0005",                          // B형 표준불확도 입력 원문 (빈칸 = 입력 안 함)
}
// 숫자 배열이 아니라 원문 문자열을 저장하고, 열 때마다 lib/stats.js 가 숫자로 해석한다.
// 화면에 계산해서 보여줄 것:
//   평균, 표본표준편차 s (n−1로 나눔, 엑셀 STDEV.S 와 같음),
//   A형 u_A = s/√n, 합성 u_c = √(u_A² + u_B²)
// 값이 1개면 s·u_A 를 계산할 수 없다. (B형만 입력하면 u_c = u_B)
```

### 계산 블록 (calc)

```js
{
  ...공통,
  type: "calc",
  name: "g",
  formula: "4*pi^2*L / T^2",   // 위쪽 블록의 name을 변수로 사용
}
// lib/calc.js 가 수식의 변수마다 위쪽 측정 블록을 찾아 { 값: 평균, 불확도: 합성 u_c } 로
// engine.js propagate()에 넘긴다. 결과: 값 ± 불확도(유효숫자 처리), 변수별 오차 기여도(막대).
// 수식에는 측정 블록의 이름만 쓸 수 있다 (계산 블록의 결과를 다시 쓰는 것은 아직 지원하지 않음).
// 같은 이름이 여러 개면 바로 위쪽(가장 가까운) 블록을 쓴다.
```

### 그래프 블록 (graph)

```js
{
  ...공통,
  type: "graph",
  name: null,
  xName: "L",               // x축으로 쓸 측정 블록 이름
  yName: "T2",              // y축으로 쓸 측정 블록 이름
  fit: "linear",            // 추세선 종류: none | linear | origin | quadratic | power | exponential | log
}
// 오차막대 + 추세선 + 결정계수(R²)
//
// 점 만들기: x축 블록과 y축 블록의 "같은 순서의 값"끼리 짝짓는다. (x의 i번째 값, y의 i번째 값)
//   값 개수가 다르면 짧은 쪽에 맞추고 경고한다. 측정 블록만 축으로 쓸 수 있다(계산 블록은 값이 하나뿐).
// 오차막대: 각 블록에 입력한 B형 불확도를 모든 점에 같게 쓴다. B형을 안 쓰면 막대가 없다.
// 추세선 유형과 식 (lib/regression.js, 모두 직접 구현):
//   linear      y = a·x + b           직선
//   origin      y = a·x               원점을 지나는 직선
//   quadratic   y = a·x² + b·x + c    2차 곡선 (정규방정식을 가우스 소거법으로 풂)
//   power       y = a·x^b             거듭제곱 (ln y = ln a + b·ln x 로 바꿔 직선 맞추기)  x, y > 0
//   exponential y = a·e^(b·x)         지수     (ln y = ln a + b·x 로 바꿔 직선 맞추기)     y > 0
//   log         y = a·ln(x) + b       로그     x > 0
// R²: 직선·원점·2차·로그는 y값에 대한 R², 거듭제곱·지수는 로그를 취한 값(ln y)에 대한 R² (엑셀과 같은 방식).
// 표준오차(± 값): 직선, 원점, 로그, 거듭제곱, 지수는 계산한다. 2차 곡선은 계산하지 않는다.
// 이름을 바꾸면 그래프 블록의 축 이름도 같이 바뀐다.
```

### 내보내기 화면

원본에서 매번 새로 계산해 보여준다 (결과는 저장하지 않는다).
- 측정 결과 표: 이름·단위·n·평균·표준편차·u_A·u_B·u_c·결과(유효숫자)
- 계산 결과 표: 이름·수식·결과(값 ± 불확도)·오차 기여도
- "표 복사": 서식 있는 표(HTML)와 탭 구분 글자를 함께 복사 → 워드·구글문서에는 표로, 엑셀에는 칸으로 붙는다
- 그래프: "이미지 저장 (PNG)"(2배 해상도), "이미지 복사"(클립보드)

## 3. 설계 규칙 (CLAUDE.md에서 확정)

1. **셀 주소가 아니라 이름으로 참조한다.** `B2`가 아니라 `L`, `T`. 실제 물리 식과 같은 모양.
2. **계산 블록은 자기보다 위 블록만 참조한다.** 순환 참조를 구조로 막는다.
   - 변수 후보 = 현재 블록보다 앞에 있는 블록들의 name.
3. **이름 중복 검사.** 같은 name이 두 개면 편집 화면에서 경고.
4. **이름을 바꾸면 그 이름을 쓰는 수식도 같이 고친다.** (`L` → `len` 바꾸면 아래 수식의 `L`도 교체)
5. **계산 결과는 DB에 저장하지 않는다.** (위 2절)

## 4. 블록 조작

- 추가: 목록 맨 아래에 추가 후 종류 선택
- 삭제: 블록 우상단 버튼. 다른 블록(계산 블록 수식, 그래프 블록 축)이 그 이름을 쓰고 있으면
  화면 안 확인 창(`ConfirmDialog`)으로 한 번 확인한다. 브라우저 기본 `window.confirm`은 이 앱의
  미리보기 환경에서 팝업 없이 조용히 취소돼버려서 쓰지 않는다.
- 이동: 위/아래 화살표 (맨 위/맨 아래에서는 비활성화). 드래그는 나중에.
- **참조 재검증**: 이름을 바꾸거나 블록을 옮기면 계산 블록 수식·그래프 블록 축이 더 이상 존재하지
  않는 이름을 가리킬 수 있다. 이때 이동·이름 변경 자체는 막지 않고 해당 블록에 노란 경고 문구를
  보여준다. 계산 블록은 그 상태에서 "계산할 수 없어요: …"라고 알려주고 결과를 내지 않는다.

# 화면·블록 구조 (1차시 확정본)

이 문서는 앞으로 만들 화면과 블록의 구조를 확정한다. 코드보다 먼저 읽는다.

## 1. 화면 구조

세 개의 화면(라우트)으로 나눈다.

| 경로 | 화면 | 하는 일 |
|---|---|---|
| `/` | 시작 화면 | 내 실험 목록(카드), 새 실험 만들기, 검색 |
| `/exp/:id` | 편집 화면 | 블록을 위→아래로 쌓아 계산 |
| `/exp/:id/export` | 내보내기 | 표 복사, 그래프 이미지 저장 |

- 6차시 전(로그인 붙기 전)까지는 실험 목록을 **브라우저 localStorage**에 저장한다.
- 6차시부터 같은 자리에 Supabase를 연결한다. 화면은 그대로 두고 저장소만 바꾼다.

### 컴포넌트 트리 (예정)

```
App                         라우터
├─ HomePage                 시작 화면
│  ├─ SearchBar
│  └─ ExperimentCard        실험 카드 1개
└─ EditorPage               편집 화면
   ├─ BlockList             블록들을 순서대로 렌더
   │  ├─ MeasureBlock       측정 블록
   │  ├─ CalcBlock          계산 블록
   │  └─ GraphBlock         그래프 블록
   └─ AddBlockButton        블록 추가 (측정/계산/그래프 선택)
```

## 2. 데이터 구조

### 계산 결과는 저장하지 않는다

원본(측정값, 수식, 축 설정)만 저장하고, 화면을 열 때마다 engine.js로 다시 계산한다.
계산 방식을 고치면 예전 실험에도 자동 반영된다.

### 실험 (experiment)

```js
{
  id: "uuid",
  title: "단진자로 중력가속도 측정",
  createdAt: "2026-09-07T...",
  updatedAt: "2026-09-07T...",
  angleUnit: "deg",        // "deg" | "rad"  — 삼각함수 각도 단위 (실험 전체 공통)
  blocks: [ ...블록 배열, 화면에 보이는 순서 ]
}
```

### 블록 공통

```js
{
  id: "uuid",
  type: "measure" | "calc" | "graph",
  name: "L",               // 다른 블록이 변수로 참조하는 이름. graph는 없음
  // type 별 추가 필드는 아래
}
```

Supabase 테이블로 갈 때: 공통 필드(id, type, 순서, name)만 열로 두고
나머지(`data`)는 JSON 한 칸에 저장한다.

### 측정 블록 (measure)

```js
{
  ...공통,
  type: "measure",
  name: "L",
  unit: "m",
  raw: [1.001, 0.998, 1.002, 1.000],   // 반복 측정값 (붙여넣기로 입력)
  typeB: 0.0005,                        // B형 표준불확도 (기기 최소눈금 등), 직접 입력
}
// 화면에 계산해서 보여줄 것: 평균, 표준편차, A형 불확도(=표준편차/√n), 합성 불확도(√(uA²+uB²))
```

### 계산 블록 (calc)

```js
{
  ...공통,
  type: "calc",
  name: "g",
  formula: "4*pi^2*L / T^2",   // 위쪽 블록의 name을 변수로 사용
}
// engine.js propagate()에 넘긴다. 결과: 값 ± 불확도(유효숫자 처리), 변수별 기여도
```

### 그래프 블록 (graph)

```js
{
  ...공통,
  type: "graph",
  name: null,
  xName: "T2",              // x축으로 쓸 블록 이름
  yName: "L",               // y축으로 쓸 블록 이름
  fit: "linear",            // 추세선 종류
}
// 오차막대 + 추세선 + 결정계수(R²)
```

## 3. 설계 규칙 (CLAUDE.md에서 확정)

1. **셀 주소가 아니라 이름으로 참조한다.** `B2`가 아니라 `L`, `T`. 실제 물리 식과 같은 모양.
2. **계산 블록은 자기보다 위 블록만 참조한다.** 순환 참조를 구조로 막는다.
   - 변수 후보 = 현재 블록보다 앞에 있는 블록들의 name.
3. **이름 중복 검사.** 같은 name이 두 개면 편집 화면에서 경고.
4. **이름을 바꾸면 그 이름을 쓰는 수식도 같이 고친다.** (`L` → `len` 바꾸면 아래 수식의 `L`도 교체)
5. **계산 결과는 DB에 저장하지 않는다.** (위 2절)

## 4. 블록 조작

- 추가: 목록 맨 아래에 추가 후 종류 선택
- 삭제: 블록 우상단 버튼. 그 이름을 쓰는 수식이 있으면 확인
- 이동: 위/아래 화살표 (드래그는 나중에). 이동하면 참조 가능 범위가 바뀌므로 재검증
